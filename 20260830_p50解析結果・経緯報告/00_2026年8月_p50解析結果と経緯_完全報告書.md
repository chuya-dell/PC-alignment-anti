# 2026年8月 p50プラズモンナノピラー解析 経緯・検証結果・結論報告書

## 1. エグゼクティブサマリー
2026年8月に実施されたp50基板を用いた本測定（計7実験）および各種対照実験の生データに基づき、詳細な検証を行いました。
従来の解析パイプラインに存在していた重大なハードキャップ（上位0.5%のみ抽出）を特定・修正した上で、真の全ピラー（1視野あたり約8〜10万本）を対象とした厳密な再解析を実施しました。

その結果、以下の決定的な事実が明らかになりました：
1. **SAM修飾による光学シグナル（コントラスト低下）の実在を実証（Proof of Principle）**
   * 同一視野内にSAM領域と未修飾領域を共存させた対照実験（`同一視野`データ）において、**SAM修飾領域のピラーコントラストが未修飾領域と比較して一貫して約30%（11.7%〜55.5%）低下**していることを確認。分子結合が光学的に捉えられていることが直接証明されました。
2. **Pre/Post相関低下の真因の特定**
   * Pre/Post全工程を経た相関低下（0.937 → 0.725）について、濃度依存性（ANOVA p=0.170, 回帰 p=0.138）やSNR・欠陥面積との相関はなく、**「周期構造におけるアフィン位置合わせ（ECC）の局所解トラップ（1ピッチズレ）」**がばらつきの主因であることが判明しました。
3. **光学系の再現性（基板着脱）は無罪**
   * 着脱のみの対照実験において、同一パイプライン（サブピクセルCubic補正＋欠陥マスク）で **r = 0.937** の高相関を達成。光学系の再現性に問題はありません。

## 2. 8月の解析パイプライン重大欠陥の特定と経緯
従来の解析パイプライン（`run_batch_alignment.py`）において、以下のコードが存在していました。

```python
thresh_val = np.percentile(pos_contrast, 99.5)
```

### 欠陥による影響
* **母集団の極端な歪み**: 正のコントラストを持つピクセルのうち上位0.5%しか抽出されず、想定「1視野16万本」に対し、実際には7,000〜48,000本しか解析されていませんでした。
* **過去全データへの影響**: 過去のp200, p100, cone50データもすべて上位ピラーのみの偏ったサブセットで評価されていました。
* **再計算による確認**: p200 1nMのNeg Grid%は全ピラー再計算で 13.66% → 13.59% とほぼ一致しますが、ブランクの標準偏差σは 0.084% → 0.229% と約3倍に増加するため、ノイズ評価の適正化が必要です。

## 3. 検証により否定された仮説群
生データに基づく直接検証により、以下の仮説はすべて否定（棄却）されました。

| 仮説 | 検証内容 | 結論 |
| :--- | :--- | :--- |
| **L3マスクの過剰除外** | Pre/Post欠陥マスク適用後のピラー通過率を算出 | **否定**: 通過率はp200で98.15%、p50で92.8〜95.9%と極めて高く、ピラーを過剰除外していない。 |
| **p50構造自体の光量不足** | 良好視野における単一ピラーの散乱光量と背景ノイズ比を計測 | **否定**: 優良視野でのSNRは2.90を確保しており、光量不足ではない。 |
| **基板着脱に伴う光学系の非再現性** | 着脱のみ実験（260704）に厳密補正パイプラインを適用 | **否定**: Pre/Post相関 **r = 0.937** を達成。着脱に起因する光学的問題は認められない。 |

## 4. p50本測定（260828-p50-SAM）全64視野の相関解析結果

全8サンプル（Sample 1 = 1nM 〜 Sample 8 = Blank）× 各8視野（計64視野）について、CV2 ECCアフィン補正＋欠陥7x7膨張マスク＋INTER_CUBIC補間による統一パイプラインでPre/Post相関を算出しました。

### 統計結果

| **S6** | 10 fM | 0.732 | 0.107 | 0.578 | 0.853 |
| **S7** | 1 fM | 0.768 | 0.110 | 0.573 | 0.887 |
| **S8** | Blank | 0.768 | 0.114 | 0.579 | 0.905 |

### 統計検定と交絡要因の分析
1. **濃度依存性の検定**:
   * ANOVA検定: $p = 0.170$（有意差なし）
   * 対数濃度との単回帰分析 (S1〜S7): $p = 0.138, R^2 = 0.040$（有意なトレンドなし）
2. **視野間ばらつきの要因分析**:
   * SNR vs 相関: $r = -0.166, p = 0.189$（無関係）
   * 欠陥面積 vs 相関: $r = -0.174, p = 0.168$（無関係）
   * **ECCスコア（位置合わせ確度） vs 相関: $r = 0.505, p < 0.0001$（極めて強い正の相関）**
   * **結論**: 相関が0.5台に崩れている視野は、周期構造ゆえにアフィン変換が1ピッチ隣に誤ロックした「位置合わせエラー」が原因でした。
